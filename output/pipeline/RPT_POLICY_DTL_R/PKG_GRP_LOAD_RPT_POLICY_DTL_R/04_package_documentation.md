## 2. Purpose & Business Context

This package body loads and enriches `RPT_POLICY_DTL_R`, the group-policy detail report table. It first stages a wide policy/billing/transaction extract from DIM/FCT sources into an exchange table (`RPT_POLICY_DTL_R_EXG`) which is partition-exchanged into `RPT_POLICY_DTL_R` (a "Kill/Fill" full-refresh pattern introduced 08-May-2026, replacing an older truncate-and-load approach, per the in-code history log). It then runs a long chain of post-load cursor UPDATE passes (`PRC_UPD_COL_DETAILS`) to populate ~18 derived/indicator columns — client name, underwriting tracking, ID-theft indicator/date, elimination period, EAP/bereavement descriptions, cross-sell flags, renewal dates, rate guarantee, plan options, agency code, submission date, and in-force indicator — each sourced from a different DIM/FCT/lookup table.

**Feeds:** `RPT_POLICY_DTL_R` (via `RPT_POLICY_DTL_R_EXG` partition exchange, then 18 in-place UPDATE passes)
**Triggered by:** Tidal job `EDP_GRP_EDW_LOAD_RPT_POLICY_DTL_R-16`
